# Solar AI

MakeCode Arcade 的單輸入感知器（Perceptron）積木，可學習「輻射值高於某門檻就是 1」這類二分類問題。

## 使用方式

1. `重設 AI`
2. 用 `加入訓練資料` 放入多筆（輻射值、答案 0 或 1）
3. `用資料集訓練 AI 最多 N 輪`（整輪無錯會提早停止）
4. 用 `AI 在資料集上的正確率` 檢查，用 `AI 預測輻射值` 預測新資料
5. `AI 學到的門檻值` 可看到 AI 找到的分界

## 限制

- 只能處理可用單一門檻分開的資料；有矛盾標籤時不會收斂
- 輸出只有 0 或 1，沒有信心值
- 輻射值會限制在 0 到 1000

> 以 MakeCode Arcade 擴充套件載入：`solar-ai-arcade`
